How to use this plan

Four difficulty levels are spread across three days: Day 1 = fundamentals, Day 2 = intermediate, Day 3 = advanced + production/scenario. Progress is saved in this browser automatically.

  • Answer out loud in 60–90 seconds before ticking a box. Recognising an answer is not the same as being able to say it.
  • Open key points only after you have attempted the answer, then compare.
  • Anything still unticked by the evening of Day 3 becomes your final revision list.
  • For every scenario question, structure the answer as: clarify → observe (metrics/logs) → hypothesis → verify → mitigate → prevent.
